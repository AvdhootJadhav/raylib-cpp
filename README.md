# Steps to run
- Downlaod the raylib binaries from https://github.com/raysan5/raylib/releases
- Then run the Makefile using `make run`
- If you would like to use GCC instead of Clang just modify the `Makefile` accordingly
- Configure the number of snowflake branches and depth in `main.cpp`
- Execute the command `make run` to render snowflake on screen
